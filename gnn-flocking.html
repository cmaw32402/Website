GNN for Flocking Control

Class Project · Multi-Robot Systems

Can a graph neural network learn multi-robot flocking from a classical controller? I trained a graph-based policy on expert demonstrations and compared its behavior with the original controller in simulation.

Simulation setup

Six E-puck robots navigated a square waypoint route through narrow obstacle passages in Webots. A classical Laplacian controller served as the expert, combining formation maintenance, waypoint navigation, and artificial-potential-field obstacle avoidance.

Learning from the classical controller

A Webots supervisor logged robot states, graph connections, and the expert's control commands. Approximately 4,000 samples were used for imitation learning: the network learned to predict the expert control vector for each robot.

GNN architecture

Each robot is a node, with edges describing neighboring robots. The model encodes robot features, exchanges information across connected neighbors, updates the node representations, and outputs a two-dimensional control vector for every robot.

Results

The GNN closely matched the classical controller's formation error and lap time. Its main weakness was obstacle avoidance, where it recorded three collisions.
